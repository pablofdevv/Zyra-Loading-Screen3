# ✨ Zyra Loading Screen 3 - Minimalist Dark Edition

Welcome to **Zyra-Loading-Screen-3**, a refined FiveM loading screen resource by **Zyra Store**. Designed with a sleek dark slate color palette and elegant Google Fonts Outfit typography for high-end roleplay servers.

## 🛠️ Key Features

- **Minimalist Dark Slate UI:** High contrast dark interface with Outfit typography and ultra-clean spacing.
- **Smooth NUI Progress Tracking:** Percentage loading bar seamlessly integrated with FiveM client events.
- **Multi-Language Support:** Ready-to-use localization framework via `locales.js`.
- **Integrated Audio Player:** Background music controller with playlist management and volume control.
- **Server Information Sidebar:** Quick panel for server rules, announcements, and official links.

---

## 📦 Installation Instructions

1. **Copy the Resource:**
   Place the `Zyra-Loading-Screen-3` folder inside your server's `resources` directory:
   `resources/[zyra]/Zyra-Loading-Screen-3`

2. **Update `server.cfg`:**
   Add this line to your `server.cfg`:
   ```cfg
   ensure Zyra-Loading-Screen-3
   ```

3. **Restart Server:**
   Save `server.cfg` and restart your server or run:
   ```cmd
   refresh
   ensure Zyra-Loading-Screen-3
   ```

---

## ⚙️ Configuration Guide (`config.js` & `locales.js`)

- **Translations:** Edit `locales.js` to modify or translate UI string tokens into any language.
- **Server Branding:** Change server name, tagline, and social media links in `config.js`.
- **Music Playlist:** Insert custom `.mp3` URLs and set default playback volume.
